# Detailed Module Scope & API: Bharat-Data

**Bharat-Data** uses static class instances globally accessible under the exported `bharat` or top-level ESM exports. The library leverages a strict deterministic model using the `SeedEngine` and features regional logic through the `LocaleEngine`.

Below is a detailed map of generated domains, covering exactly what methods are available and what they yield.

---

## 1. Identity Module (`Identity`)
Used to generate personal and tax-related Indian identifications matching valid governmental structures.
*   `Identity.aadhaar()` - Returns a 12-digit structural string (Format: `XXXX XXXX XXXX`).
*   `Identity.pan(surnamePrefix?)` - Returns 10-char PAN string containing 5 letters, 4 digits, 1 letter.
*   `Identity.voterId(stateName?)` - Returns Epic Number patterns based on state code.
*   `Identity.passport()` - Returns standardized Passport identifier (1 Letter + 7 Digits).
*   `Identity.tan()` - Returns Tax Deduction and Collection Account Number (4 Letters, 5 Digits, 1 Letter).
*   `Identity.epf()` - Returns Employee Provident Fund structure string.
*   `Identity.esic()` - Returns 17-digit ESIC Identification code.

## 2. Business Module (`Business`)
Used to mock structural corporation data, B2B elements, and B2C enterprise domains.
*   `Business.corporatePan(isFirm?)` - Returns an entity PAN string (Format contains `C` or `F` at index 3).
*   `Business.gstin(stateCode?)` - Returns complete 15-char GST structure tied to state code limits.
*   `Business.udyam(stateCode?)` - Returns `UDYAM-XX-XX-XXXXXXX` MSME registration digits.
*   `Business.companyName()` - Generates naming structures using real business suffixes (e.g. `Pvt. Ltd.`, `LLP`, `and Sons`).
*   `Business.industry()` - Generates sectors (e.g., `Technology`, `Healthcare`, `Finance`).

## 3. Person & Names (`Names`, `Person`)
Mocks exact regional First & Last mappings based on language arrays, alongside cohesive multi-attribute profiles.
*   `Person.generate(region?)` - Returns a comprehensive `UserProfile` object containing paired Names, Contact info, Addresses, and Identifications.
*   `Person.bulk(count, region?)` - Returns `n` arrays of `UserProfile` structures.
*   `Names.firstName(region?, gender?)` - Returns purely Indian forename.
*   `Names.lastName(region?)` - Returns matching regional surname.
*   `Names.fullName(region?, gender?)` - Complete space-separated name strings ensuring correct locale syntax.

## 4. Phone & Internet (`Phone`, `Internet`)
*   `Phone.mobile(includePrefix?)` - Returns 10-digit cellphone string optionally with `+91` attached.
*   `Phone.landline(cityName?)` - Local area codes mapped to Indian cities followed by 7-to-8 digits.
*   `Internet.email(firstName, lastName)` - Sanitized lower-case string matching prominent Indian hostnames (e.g. `rediffmail.com`).
*   `Internet.userName(firstName, lastName)` - Safely generated slugified handle strings.
*   `Internet.url()` / `Internet.password()` - Standard mock implementations.

## 5. Address Module (`Address`)
Provides state-accurate geographic mapping.
*   `Address.state(region?)` - Generates localized states.
*   `Address.city(stateCode?)` - Maps city to generated mock states.
*   `Address.pincode(stateCode?)` - Returns valid 6-digit PIN configurations mapped correctly by region prefixes.

## 6. Infrastructure: Transport & Healthcare (`Transport`, `Healthcare`)
*   `Transport.vehicleNumber(stateCode?)` - Generates high-fidelity RTO registered plates (Format: `MH-12-XX-XXXX`).
*   `Transport.dlNumber(stateCode?)` - Generates state-issued Driving License formats. 
*   `Healthcare.abhaId()` - Returns India's standard 14-digit ABHA Health ID Number.
*   `Healthcare.bloodGroup()` - String literals mapping physiological outputs (`A+`, `O-`, etc).
*   `Healthcare.hospital()` - Appends randomized clinical suffixes to prominent titles (`Lifeline`, `Apollo`, etc).
*   `Healthcare.insurancePolicy()` - Strict alpha-numerical mock of standard insurance.

## 7. Education (`Education`)
*   `Education.university()` - Institutional prefixing (e.g., `Indian Institute of...`).
*   `Education.degreeInfo()` - Outputs an object specifying Stream + Programme (ex. `{type: 'B.Tech', stream: 'Electrical'}`).
*   `Education.rollNumber()` - Mock registration ID patterns (`YY-Dept-ID`).

## 8. Financials, Utility & Gadgets (`Finance`, `Utility`, `Gadget`)
*   `Finance.ifsc()` - Validated Indian Financial System Code strings (4 letters + `0` + 6 digits).
*   `Finance.accountNumber()` - Sanitized numerical string.
*   `Gadget.mobile()` / `Gadget.tv()` - Strings mapping prominent B2C Indian consumer electronic markets.
*   `Utility.price()`, `Utility.gstRate()`, `Utility.category()` - Helper functions for E-commerce mocking.
*   `Utility.phrase()` - Generates hinglish or professional phrases (`Zabardast`, `Jugaad`, `Scalable`).
